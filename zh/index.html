Brat Animator

一个静态浏览器工具，可以把同步 LRC 歌词转换成方形 brat-style 歌词视频，支持本地音频 timing 检查和 video-only MP4/WebM 导出。

功能

  • 通过 LRCLIB 搜索，或粘贴带时间戳的 LRC 歌词。
  • 在浏览器中预览并优化歌词 timing。
  • 导出前自定义方形 canvas。

导出

  • 浏览器支持时导出 video-only MP4。
  • 兼容浏览器可使用 WebM fallback。
  • Project snapshots 和 JSON 交接工具。

需要授权

使用、复制、再分发、self-hosting、商业用途或集成都需要作者的明确书面许可。
