Brat Animator

A static browser tool for square brat-style LRC lyric videos, local timing, background media, project snapshots, and MP4/WebM export with optional loaded audio.

Site links Main app English Russian Chinese Sitemap

Features

  • Search LRCLIB, paste LRC lyrics, or use a YouTube link as a reference preview.
  • Edit lyric timing, word animation, format presets, and background media in the browser.
  • Save snapshots, export project JSON, and import preset libraries.

Export

  • Fast MP4 remains video-only when supported.
  • Realtime MP4/WebM export can merge loaded local or direct CORS-enabled media audio.
  • YouTube is never downloaded or extracted.
