Brat Animator

A static browser tool for creating square brat-style lyric videos from synced LRC lyrics, optional local audio timing, and video-only MP4/WebM export.

Features

  • Search LRCLIB or paste timestamped LRC lyrics.
  • Preview and refine lyric timing in the browser.
  • Customize the square canvas before export.

Export

  • Video-only MP4 export when supported.
  • WebM fallback in compatible browsers.
  • Project snapshots and JSON handoff tools.
